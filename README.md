# xrwvm-fullstack_developer_capstone

## Project: Best Cars Dealership

### Project Description
Best Cars Dealership is a full-stack web application for a national car dealership network, built as part of the IBM Full Stack Software Developer Professional Certificate capstone project.

### Technology Stack
- **Frontend:** React.js, Bootstrap CSS
- **Backend:** Python, Django
- **Database Microservice:** Node.js, Express, MongoDB
- **Sentiment Analysis:** IBM Watson NLU / TextBlob
- **CI/CD:** GitHub Actions
- **Deployment:** IBM Code Engine / Kubernetes

### Project Structure
```
xrwvm-fullstack_developer_capstone/
├── server/
│   ├── djangoapp/          # Django application
│   ├── frontend/           # React frontend
│   │   ├── static/         # HTML static pages
│   │   └── src/            # React components
│   └── database/           # Database backend service

```

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run migrations: `python manage.py migrate`
4. Start server: `python manage.py runserver`
